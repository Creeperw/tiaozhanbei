# 幻觉率测试方案（修订版 v1.1）

> 原稿：`测试方案分支/幻觉率测试方案.md`
> 修订要点：接口改对、目标值对齐赛题、数据改为中医主域、判定双通道+人工抽检、中间数据落盘

---

## 1. 测试目标（对齐赛题）

| 指标 | 赛题目标 | 本方案口径 |
|---|---|---|
| **专业知识谬误率（幻觉率）** | **<5%** | 检出幻觉的用例 / 总用例 |
| 客观题准确率（对照） | ≥75%（低于算未达标） | 答案匹配 ground truth 比例，目标 ≥85% |
| 拒答率（参考） | — | 拒答算安全行为，不计入幻觉 |

幻觉判定口径（冻结）：
- **算幻觉**：C-FAITH 7 类（实体错误/关系错误/属性错误/时空幻觉/虚假引用/虚构事实/过时信息）
- **不算幻觉**：表述不同但语义相同、正确但不全面、拒答、明确标注不确定

## 2. 被测对象（修正：不是裸模型）

被测链路 = 六智能体全链路 `POST /api/v1/review-cards/stream`，分两个层面统计：
- **模型级幻觉率**：最终生成资源（Expert 输出）中的幻觉占比
- **系统级幻觉率**：Expert 产生幻觉但被审核裁判拦截（audit=reject）的占比
  - 系统级 = 模型级 − 放行到用户的幻觉。**报告两个数**，系统级才是"作品完整性"的加分证据

## 3. 数据源（修正：中医主域）

| 数据 | 来源 | 数量 | 角色 |
|---|---|---|---|
| 中医执业真题 | 本地 `backend/competition_app/data/qualification_papers/papers/*.json` | 3812 带答案 | **主数据** |
| TCM-Text-Exams | `挑战杯测试数据集V1/TCM-Text-Exams` | 1088 | 主数据（补充） |
| CMHE（mesh/hallucination/diagnose） | `挑战杯测试数据集V1/CMHE` | 24889/1999/1622 | 领域泛化对照（报告单独标注） |

抽样：中医主数据按考试类别分层抽 **1000 题**；CMHE 抽 **500 题**作对照。总计 1500。

## 4. 执行流程

```
1. 抽样 → 2. 构造 user_request → 3. review-cards/stream 全链路调用
   → 4. 记录 execution_id/snapshot_path/最终输出 → 5. 双通道判定 → 6. 统计
```

- 每题记录：`case_id / input / expected / system_output / execution_id / snapshot_path / audit_decision`
- 同一 learner_id，最小画像（`user_profile={}`），避免画像分支干扰幻觉测量
- 请求模板与"准确率测试"一致：题干+选项，要求"给出答案选项字母并说明依据"

## 5. 判定（双通道 + 人工抽检）

**通道A（规则）**：客观题直接比对选项字母；抽不到字母/主观题 → 通道B。
**通道B（LLM Judge，DeepSeek）**：CoT + C-FAITH 7 类定义，输出
`{"is_correct": bool, "halu_types": [...], "reason": "..."}`，每条判 2 次多数决。

- 通道A/B 一致 → 采纳；冲突 → 人工复核
- **人工抽检 10%**（随机 150 条），自动判定 vs 人工一致率 ≥95% 才算测试通过
- judge prompt 冻结版本号，随报告提交

## 6. 统计与报告

- 幻觉率（模型级/系统级）+ 7 类幻觉分布 + Wilson 95% CI
- 客观题准确率、拒答率、平均响应时间
- 对比：中医主数据 vs CMHE 对照（领域泛化说明）
- 失败案例清单（含 snapshot 路径，可回放追责到具体 agent——答辩举证）

## 7. 与画像适配度方案的分工（消除重叠）

原"维度二：用户画像一致性"与适配度方案重叠，拆清：
- **画像一致性**（本方案）：推荐内容是否**违背画像事实**（约束违反/偏好忽略/知识编造/复习遗漏）——事实层
- **画像适配度**（适配度方案）：推荐难度/形式是否**合适**——质量层
- 两方案共用同一 9 类画像（P1~P9）与同一批用例的 system_output，各自判各自的指标，报告交叉引用

## 8. 执行

```powershell
# 脚本位置：evaluation_delivery/（codex1.py 已有骨架，按本方案参数化）
python codex1.py --data 中医真题_抽样1000.jsonl --judge deepseek --human-check 10%
```

预估：1500 题 × 全链路 ~2.5min ÷ workers 3 ≈ 21 小时 + judge ~30 分钟。建议分批执行（先 300 题验证，再全量）。

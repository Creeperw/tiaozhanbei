# 上传处理收敛：第三阶段

## 范围与入口

统一资源页位于 `/personalization/resources`，提供教材阅读、个人知识资料、个人题库、考纲四种固定用途，由用户选择，不从文件名推测用途。

- 教学资源中的教材按钮打开统一页面并预选教材阅读。
- 个人知识库上传按钮打开统一页面并预选个人知识资料；个人区域拖放会前往统一面板，提示重新选择文件，不自动提交丢入的文件。
- 知识库的个人题目工作区保留历史、修订、确认及停用操作，上传按钮前往统一页面并预选个人题库。
- 公共资料与管理员审核权限及入口不变。
- `PersonalizationHubPage` 传递显式 `uploadType` 和导航回调。类型参数保留在应用导航状态中，没有增加新的 URL 子路径；直接刷新统一页仍可重新选择类型。

## 复用边界

`resource-upload/knowledgeUpload.js` 提取原资料上传请求编排，供统一表单和旧页面适配调用；PDF、Markdown、TXT 仍调用正式个人资料接口，JSON、JSONL 和公共资料仍走原接口。没有复制知识库目录、删除、重建或管理面板。

教材复用 `TextbookLibrary` 中的上传表单，增加内联显示模式；原独立使用方式仍兼容。题库、考纲复用各自原页面及业务操作。

题库解析完成仍需手动确认。考纲仍按既有行为在解析成功后自动激活；统一面板在提交前明确提示会替换当前激活考纲、影响练题与讲解。

## 状态与结果

- 新 `UploadProgress` 消费第二阶段只读进度合同，无虚构百分比；未识别状态显示待核实。
- 教材历史仅通过已鉴权的任务列表读取；运行中定时刷新，失败可手动刷新。中断记录不提供自动重放。
- 教材提交后的状态查询失败可重新查询，不重复 POST。运行期间阻止重复提交和面板内类型切换。
- 教材完成后清理教材目录及教学资源页面缓存，提供章节阅读导航。
- 知识资料提供个人知识库导航；旧格式文件接收不等于索引完成。异常提示先核实是否部分导入，不自动重试。
- 题库仍可在当前面板预览、修订和确认，也可前往个人题库；考纲保留当前页结构查看和激活管理。
- 正在上传时显示勿刷新/切页提示，并注册浏览器离开警告；不拦截全局应用导航，也不承诺跨页面保留所有未提交表单或自动恢复请求。

## 验证

- 新增专项测试 12 项，覆盖四类选择、预选与激活提示、忙碌保护、教材内联及结果导航、缓存清理、查询失败仅重查、历史中断、资料适配与部分失败提示。
- 原入口另补 2 项测试：教材按钮转交统一入口、个人知识库按钮预选跳转。
- 前端完整回归：89 个测试文件、681 项通过。使用原 `test:unit` 命令附加 `--maxWorkers=2`；首次默认并发出现超时，降低并发后原超时及断言均未改动。
- 生产构建成功。仍有既有 Browserslist 数据陈旧、较大 bundle 和测试 canvas 提示。
- 本轮核心文件 ESLint 和指定文件 diff 空白检查通过。`PersonalizationHubPage` 原有动画 effect 有 1 项错误、1 项 warning，通过对备份执行相同检查确认已存在，未扩大修改范围。
- 本机 Playwright 对生产构建做隔离 API mock 验证：四类切换、教材无嵌套弹窗、考纲警告通过；390px 窄屏无页面横向溢出。截图位于 `/tmp/upload-phase3-desktop.png` 与 `/tmp/upload-phase3-mobile.png`。
- 浏览器验证未提交真实文件，未连接真实后端，不构成 Live 上传验收。集成浏览器拦截未稳定生效，后改为本机 Playwright 单次执行隔离验证。

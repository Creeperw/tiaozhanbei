# 时珍智训三项创新点与场景化问题价值分析

## 一、三项核心问题与创新点

### 创新点一：证据约束与可追责的多智能体协同机制

**核心问题分为两部分：**

1. **平台层面：**现有大部分学习平台难以让专业错题讲解做到有证据、可追踪，并能在出错后进行局部修复。
2. **多智能体框架层面：**常见多智能体框架往往缺少统一的证据绑定、协作边界、审核门禁和局部返修机制，难以保证各智能体输出可靠，并准确定位和修复具体错误。

**系统解决方案：**将复杂请求拆分为多个职责明确、按需通信的智能体任务：Planner 负责任务分解，知识检索智能体负责查找教材和题库证据，专家智能体负责生成讲解与变式题，Audit 智能体负责审核专业声明；发现错误时只返修出错节点，并将学生反馈和任务结果写回学习状态。

**协同流程：**

```text
任务分解 → 证据检索 → 专业生成 → 审核 → 局部修复 → 学生反馈与状态更新
```

**直接价值：**让足三里定位、主治、操作禁忌等关键结论有来源，能够追踪参与角色和执行步骤，并在专业声明或变式题出错时进行局部修复，避免整条流程重复生成。

### 创新点二：安全约束下的多时间尺度学习路径自主规划与自适应机制

**核心问题：**现有大部分学习平台难以根据变化的客观事实，制定动态变化、真正可执行的学习规划或学习路径。

**系统解决方案：**将考试目标、教材体系、知识图谱、先修知识、薄弱知识点、复习到期和可用时间放入同一个路径生成过程，分为宏观考试路线、中观阶段计划和微观当日任务三级规划；候选任务先经过路线、先修、时间、复习状态和资料可信度等约束校验，再进行排序和调度。当客观事实发生变化（可用时间、掌握度、任务完成状态、复习到期等），系统按优先级自动缩短、拆分、延后或重排任务，全程无需学生干预。

**直接价值：**把“推荐相关课程”转化为“安排当前任务”。当学生可用时间从 60 分钟变为 20 分钟，系统自动按优先级拆分任务、压缩非关键内容、延后到期复习——学生无需手动调整，任务始终“能完成”。

> **与创新点三的分界：**创新点二由**客观事实**触发、由**系统自主**执行，解决计划“可执行性”；学生主观表达（错因、难度、偏好）的纠正与反馈属于创新点三。两者是接力关系而非平行关系。

### 创新点三：人机协同的用户纠偏与可解释决策闭环机制

**核心问题：**现有大部分学习平台难以让学生理解并纠正系统判断，也难以让学生反馈真正影响后续学习决策。

**系统解决方案：**展示推荐依据、使用的学习数据及其影响的计划节点，让学生看懂“为什么这么推荐”；允许学生确认、拒绝或更换任务，并把学生对错因、难度和任务效果的主观反馈写入画像更新，作为下一轮路径生成的正式输入。学生表达“今天只有 20 分钟”这类时间约束变化后，具体缩短与拆分由创新点二的系统自动执行。

**直接价值：**学生可以把“基础薄弱”纠正为“题干辨析失误”，把“题目太难、讲解太浅”等主观感受写入画像，避免错误画像持续固化，让下一轮推荐建立在被纠正过的判断上。

> **与创新点二的分界：**创新点三由**学生主观判断**触发、由**学生主动**干预，解决计划“可接受性与可纠正性”；客观事实变化触发的自动重规划属于创新点二。两者是接力关系而非平行关系。

### 三项创新点总览

| 核心问题                                               | 对应创新点                                     | 决策主体         | 系统机制                                                       | 直接价值                                   |
| ------------------------------------------------------ | ---------------------------------------------- | ---------------- | -------------------------------------------------------------- | ------------------------------------------ |
| 专业错题讲解难以做到有证据、可追踪、可修复             | 证据约束与可追责的多智能体学习任务协同         | AI 执行层        | 任务分解、证据绑定、审核门禁、执行追踪、局部修复               | 专业结论有依据，错误可定位、可修复         |

## 二、贯穿场景与整体闭环

典型场景是：一名准备中医执业医师考试的学生，在“针灸学—足三里定位、主治与操作禁忌”知识点上连续答错，距离考试还有 30 天，通常每天只能学习 60 分钟；当天临时变化后，可用时间缩短为 20 分钟。学生希望系统解释错因、生成同类题、安排复习，并根据反馈调整计划。

系统围绕该场景形成以下闭环：

```text
学生提出足三里错题并提供考试日期、可用时间
      ↓
多时间尺度路径生成
      ↓
Planner 分解学习任务
      ↓
知识检索与多智能体协同
      ↓
证据审核与局部修复
      ↓
学生完成任务；或表达主观纠正（错因、难度、偏好）供系统采纳
      ↓
系统按客观事实（时间、掌握度、完成状态）自动重规划
      ↓
更新学习状态并生成下一轮路径
```

三项创新分别约束三个层面：

| 层面       | 解决的问题                         | 决策主体         | 关键机制                                       |
| ---------- | ---------------------------------- | ---------------- | ---------------------------------------------- |
| AI 执行层  | AI 如何可信地执行学习任务          | 多智能体         | 证据绑定、审核裁判、局部修复                   |
| 学习规划层 | 系统如何自主生成可执行的学习路径   | 系统（机器自主） | 多时间尺度规划、硬约束校验、客观变化自动重规划 |
| 人机交互层 | 学生如何理解并纠正系统判断         | 学生（用户主动） | 推荐解释、用户纠偏、反馈写回画像               |

## 三、关键机制说明

### 3.1 创新点一的执行链路

| 步骤               | 主要职责                                         | 可追踪内容                     |
| ------------------ | ------------------------------------------------ | ------------------------------ |
| 任务规划           | 将请求拆为错因解释、教材举证和同类题生成         | 任务类型、参与角色、风险等级   |
| 证据检索           | 检索足三里对应教材段落、知识点和相关题目         | 教材版本、证据 ID、题目来源    |
| 专业生成           | 根据证据解释错误选项并生成目标一致的变式题       | 专业声明、目标知识点、使用证据 |
| 审核裁判           | 检查定位、主治、禁忌等声明是否有证据支撑         | 审核状态、风险、返修原因       |
| 局部修复           | 只重新运行出错的出题或审核节点                   | 被修复步骤、修复依据、最终状态 |
| 学生反馈与状态更新 | 接收错因、时长和完成情况反馈，触发下一轮路径生成 | 反馈内容、状态变更、下一轮任务 |

### 3.2 创新点二的路径约束

- **宏观层：**确定考试目标、学习阶段、教材体系和知识图谱；
- **中观层：**安排周计划、短期目标、薄弱知识点和到期复习任务；
- **微观层：**根据当前题目、即时反馈、掌握度和剩余时间决定当天动作。

候选任务生成前，系统检查目标路线、先修知识、复习状态、可用时间、资料可信度和任务承载能力，只有通过约束校验后才进行排序和安排。规划落地后，系统持续监控客观事实（可用时间变化、任务完成状态、掌握度变化、复习到期），一旦变化即按优先级自动重算：先压缩或拆分非关键任务，再延后到期复习，保证剩余预算内任务始终可完成——整个过程无需学生手动干预。

### 3.3 创新点三的反馈入口

学生可以在学习前确认目标、时间和诊断结果，对不理解之处发起追问；学习中确认、拒绝或更换推荐任务，并表达“今天只有 20 分钟”这类时间约束变化；学习后评价难度、有效性和相关性，纠正系统对错因的判断。系统将这些主观反馈写入画像更新，作为下一轮路径生成的正式输入，而不是只作为一次性的满意度评价。学生表达的时间约束变化会触发创新点二的自动重规划，由系统完成具体任务调整。

## 四、场景价值与验证指标

| 创新点             | 场景价值                                       | 建议验证指标                                                                       |
| ------------------ | ---------------------------------------------- | ---------------------------------------------------------------------------------- |
| 多智能体可信执行   | 降低专业知识误导风险，提升问题定位和返修效率   | 引用正确率、证据覆盖率、错误拦截率、局部修复成功率、专家审核一致性                 |
| 多时间尺度路径自主规划与自适应 | 客观变化下任务始终可完成，减少计划冲突、超时任务和无效内容堆叠 | 不同时间预算下的完成率、计划冲突率、超时任务比例、自动重规划成功率、到期复习完成率 |
| 人机协同的用户纠偏与可解释决策闭环 | 防止错误画像固化，提高推荐可理解性和任务适配性 | 推荐理由理解度、计划接受率与完成率、画像纠正成功率、用户信任与自主权评价           |

当前系统能够主张：

> **已形成证据约束、过程展示、审核门禁、局部修复、多时间尺度路径生成和学生反馈闭环等机制。**

## 五、竞品比较与表述边界

现有综合平台已经具备课程资源、AI 助教、学习推荐、测验和数据分析等能力。因此，本项目不应声称其他平台没有 AI、推荐或学生反馈，也不应把“拥有功能”本身作为创新依据。

更准确的表述是：

> **时珍智训面向中医药资格考试的具体任务，将多智能体协同、教材与题库证据、审核门禁、局部返修、考试路径约束、系统自主规划与学生主动纠偏统一到一个可追踪的学习闭环中。创新重点不是单项功能，而是这些机制在错题讲解、有限时间备考和系统误判纠正三个场景中的协同融合。**

当前不能直接主张：

- 多智能体一定比单智能体更准确；
- 该路径一定提高考试通过率；
- 该机制已经显著提高学习动机或成绩；
- 全面领先现有平台或“国内唯一”。

> **总体概括：专业回答不可信，就用证据约束和局部修复保障可信执行；客观事实变化让计划不可执行，就用多时间尺度与硬约束让系统自主重规划；系统判断不可理解、不可纠正，就用解释与用户纠偏闭环修正画像与决策。客观事实变了，系统自己改计划；主观认知错了，学生帮系统改判断。**

## 二、配合意愿 — 完整场景库

### 场景 1：患者愿意配合 (willing)

| 项目 | 内容 |
|------|------|
| **场景标签** | `willing` |
| **患者话术** | "医生，我听说针灸挺管用的，您就给我扎吧，我不怕。" |
| **正确回应** | "好的，感谢您的信任。我先跟您说明一下：今天取三个穴位，分别在项后和手上。进针时会有微微酸胀感，这叫「得气」，是起效的标志。过程中有任何不适随时跟我说，好吗？" |
| **错误回应1** | "那你趴好别动就行了。"（缺乏沟通、冷漠） |
| **错误回应2** | "针灸可不是闹着玩的，扎错了会出事的。"（制造恐慌） |
| **核心考点** | 即使患者配合，也要充分告知（穴位、感觉、安全措施）——体现知情同意原则 |

### 场景 2：患者犹豫担心 (hesitant)

| 项目 | 内容 |
|------|------|
| **场景标签** | `hesitant` |
| **患者话术** | "医生，我从来没扎过针……会不会很疼啊？我听人说针灸挺吓人的，针那么长……" |
| **正确回应** | "您的担心很正常，第一次接触针灸的人都会有。我给您解释一下：针灸针非常细，直径只有0.25-0.35毫米，比平时打针的针头细十倍还不止。感觉呢，不是「疼」，而是一种「酸、麻、胀」，我们叫得气。我先在您手上试一针合谷穴，您感受一下，不舒服我马上停，可以吗？" |
| **错误回应1** | "不扎针病好不了，忍着点吧，大家都这么过来的。" |
| **错误回应2** | "那您先回去吃退烧药吧，什么时候想扎了再来。" |
| **核心考点** | 用事实（针的粗细）打消恐惧 + 试针承诺降低心理门槛 + 给患者控制感（随时可停） |

### 场景 3：患者明确拒绝 (refusing)

| 项目 | 内容 |
|------|------|
| **场景标签** | `refusing` |
| **患者话术** | "不行不行，我坚决不扎针！我晕针，看见针就心慌。有没有别的办法？" |
| **正确回应** | "理解理解，晕针的人确实不适合强求。您这个情况，针灸效果会比较好，但我们可以换一种方式：用艾灸代替，不破皮，只是温热刺激，同样取大椎、曲池这些穴位。或者也可以先用耳穴贴压，贴在耳朵上，没有任何创伤。您觉得哪种能接受？" |
| **错误回应1** | "你这病不扎针好不了，你自己看着办吧。"（胁迫式） |
| **错误回应2** | "那行，给你开点药回去吃吧。"（未提供替代针灸方案） |
| **核心考点** | 尊重患者意愿 + 提供针灸体系内的替代疗法（灸法、贴压）+ 不放弃治疗 |

## 四、位置容差参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `positionTolerance` | **15 px** | 以穴位标准坐标为中心的圆形判定半径 |
| 优秀阈值 | **≤ 5 px** | 几乎零偏差 |
| 合格阈值 | **5 - 15 px** | 临床可接受范围 |
| 不合格 | **> 15 px** | 超出安全边界，可能误中他穴或危险区 |

15px 的设定依据：以图片宽度约 700px 对应人体实际宽度 ~40cm 估算，15px ≈ 0.86cm，约等于手指同身寸的 1/3，在临床操作中是合理的容差范围。后续可根据实际图片分辨率等比调整。

# 系统经典学习路径制定参考方法与文献汇报

> 汇报日期：2026-08-03
> 适用范围：时珍智训平台「经典路径（经典教材路线）」的制定方法、数据来源与文献依据

## 一、经典学习路径是什么

系统里的「经典路径」（经典教材路线）是**预置的、经过专家审核并版本化的参考学习路线**，与「个性化路径」（AI 针对单个用户实时生成）相对。它回答"考这个证、学这个方向，按什么顺序学哪些教材"的问题，不是模型每次对话现编的，而是由数据文件固化、前端通过只读接口暴露。

### 1.1 相关数据文件

| 文件 | 作用 |
|---|---|
| `backend/competition_app/data/textbook_routes/tcm_textbook_routes.v1.json` | **经典教材路线**：7 条（中医执业医师、针灸推拿、中医骨伤、中药学/执业药师、中西医结合临床、护理、中医养生治未病），每条含阶段、教材清单、前置课、等价教材组、晋级证据 |
| `backend/competition_app/data/default_routes/tcm_routes.v1.json` | **默认资格路线**：资格绑定、阶段划分、来源编号（`src-*`）、个性化规则、刷新规则 |
| `backend/competition_app/data/qualification_targets/tcm_qualification_targets.v1.json` | 五类资格考试 → 教材路线映射 |
| `competition/中医药教材默认路线-最简版.md/json` | 最原始的专家梳理稿（"选路线 → 找最低未完成阶段 → 挑 1—2 本书"） |
| `backend/competition_app/data/textbook_pdfs/catalog.v1.json` | 教材 PDF 全集索引（十四五规划教材，94 本） |

### 1.2 对外暴露接口

| 接口 | 用途 |
|---|---|
| `GET /api/v1/learning-routes?status=approved&q=` | 经典教材路线目录（只读、非个性化） |
| `GET /api/v1/learning-routes/{route_id}` | 单条经典路线的阶段、教材、来源详情 |
| `GET /api/v1/qualification-targets` | 五类资格考试及其教材路线映射 |

## 二、制定参考方法（方法论）

### 2.1 总原则

> 考试大纲/专业目录 = 确定**覆盖什么**；国家教育/培训标准 = 确定**能力阶段与宏观主线**；高校培养方案 = 提供**课程顺序、学时、实践样本**；省级细则/年度公告 = 决定**当前可用版本**；模型 = 只在默认主线内按个人基础和时间调整。

### 2.2 阶段拆分方法

按"从易到难、从基础到应用"的逻辑拆分，每阶段包含目标、教材、晋级证据（`exit_evidence`）。

以中医执业医师路线为例（0—4 共五个阶段）：

```text
0 资格与大纲绑定 → 1 中医基础语言与诊断框架 → 2 中药方剂与治法体系
→ 3 临床病证与专科整合 → 4 实践技能贯穿训练与综合模拟
```

每条路线还定义了：

- `prerequisites`：前置课（如"进入方剂学前需要中医诊断基础"）；
- `equivalence_groups`：等价教材组（如《人体解剖学》≡《系统解剖学》，选一为主、另一补差）；
- `exit_evidence`：晋级验收证据（如"完成基础辨证练习"），只有证据核验通过才推进下一阶段。

### 2.3 关系生成规则

| 关系 | 含义 |
|---|---|
| `HARD_PREREQUISITE` | 有明确能力依赖或专家确认，未满足不进入 |
| `SOFT_PRECEDES` | 多数培养方案/教材逻辑支持，用户强基础时可压缩 |
| `CAN_PARALLEL` | 不同方案同阶段或没有关键能力阻断，时间不足时选主线 |

### 2.4 来源等级体系

| 等级 | 来源 | 在系统中的作用 |
|---|---|---|
| A | 国家法律、部委标准、国家考试机构大纲、规培标准 | 定义资格、考试范围、宏观顺序、临床能力和安全边界 |
| B | 高校正式培养方案 | 提取课程顺序、学期、学分、学时、实践和多路径样本 |
| C | 专家审核与比较研究 | 解决标准冲突、形成默认顺序、持续校准 |

### 2.5 完整构建链路

```text
官方文件/培养方案
→ 课程、学期、能力阶段、实践要求等原始证据
→ 教材/课程关系候选
→ 专家审核
→ approved 默认路线
→ 用户个性化计划
```

审核清单要求：每个阶段都有来源编号；考试大纲只用于覆盖、不得被误用为顺序依据；每条 `HARD_PREREQUISITE` 都有专家审核或明确证据；冲突的高校方案不被强行平均；路线版本、来源版本、审核日期和变更原因均记录；当前年度大纲、目录、资格条件和省级细则已复核。

## 四、证据边界与声明

- 通用教育研究不自动证明对每种中医药知识或临床能力都有同等效果；系统支持本地验证：比较不同路径下的完成率、测评改进、主观负荷和导师评分。
- 涉及中医临床高级素养时，最终能力判断仍需要导师、带教医师或正式评价机制。
- 经典路线是系统根据来源综合出的默认规划模板，不是任何主管部门发布的逐本教材学习顺序；每年需按最新大纲、目录、资格条件和省级细则复核。

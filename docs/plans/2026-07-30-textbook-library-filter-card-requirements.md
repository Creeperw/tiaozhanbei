# 教学资源页“教材学习”筛选与教材卡片需求文档

## 1. 文档目的

本文定义教学资源页“教材学习”区域的教材范围、状态分类、数据来源、卡片字段、悬浮描述交互和验收标准。

目标界面以用户提供的参考图为视觉方向。本阶段先明确并复用现有前端接口，不新增后端接口，也不修改业务代码。

本区域必须展示当前登录用户的真实学习状态。前端不得硬编码章节数、知识点数、学习进度、当前教材或计划归属。

## 2. 当前前端实现

### 2.1 页面与组件

- 教学资源页主体：`frontend/llm/src/components/DashboardPage.jsx`。
- 教材列表组件：`frontend/llm/src/components/workshop-textbook/TextbookLibrary.jsx`。
- 教材列表样式：`frontend/llm/src/components/workshop-textbook/textbookLibrary.css`。
- 教材封面和描述：`frontend/llm/src/components/workshop-textbook/textbookMetadata.js`。
- 教材分类标签兼容映射：`frontend/llm/src/components/workshop-textbook/textbookPlanning.js`。
- 教材目录页：`frontend/llm/src/components/workshop-textbook/TextbookChapterLearning.jsx`。
- 教材进度接口封装：`frontend/llm/src/components/workshop-textbook/textbookChapterApi.js`。
- Atlas 接口封装：`frontend/llm/src/components/knowledge-atlas/knowledgeAtlasApi.js`。
- 学习计划与教材进度归一化：`frontend/llm/src/components/learningPlanDashboard.js`。

### 2.2 当前能力与缺口

当前 `TextbookLibrary` 已支持：

- 展示教材封面、分类标签、书名和描述；
- 按书名或描述搜索；
- 点击教材进入教材目录；
- 有长期计划时优先显示计划教材，并可展开全部教材。

当前尚未满足：

1. 没有“全部教材、学习中、未开始、已完成、已加入计划”五个筛选项；
2. 卡片没有展示章节总数、知识点总数和真实学习进度；
3. 没有统一标记“当前在学”教材；
4. “已加入计划”当前容易被误解为当前阶段教材，实际应为整个长期计划所有阶段的教材并集；
5. 描述文字当前长期占据卡片正文，而不是悬浮或键盘聚焦后显示；
6. 当前列表的计划优先展示逻辑不能代替明确的“已加入计划”筛选；
7. 当前只加载首屏需要展示的教材，没有为“计划教材优先展示、展开后再加载全部教材”补齐按需进度加载和统一状态归一化。

## 3. 已定位的现有数据来源

| 数据能力 | 现有接口或前端来源 | 关键字段 | 本需求用途 |
| --- | --- | --- | --- |
| 全量教材目录 | `GET /api/knowledge/atlas/nodes?level=1&route=textbook_14_5` | `nodes[]` | “全部教材”的权威集合 |
| 教材名称 | 同上 | `nodes[].name` | 书名和跨接口关联键 |
| 章节总数 | 同上 | `nodes[].children_count` | 卡片“X 章” |
| 知识点总数 | 同上 | `nodes[].count` | 卡片“X 个知识点” |
| 教材章节列表 | `GET /api/knowledge/atlas/nodes?level=2&route={route}&lv1={book}` | `nodes[]`、`children_count` | 获取每章有效小节数，并继续加载有效小节 ID |
| 教材有效小节 | `GET /api/knowledge/atlas/nodes?level=3&route={route}&lv1={book}&chapter_id={chapterId}` | `nodes[].id` | 进度分母和历史 ID 有效性校验 |
| 用户教材学习记录 | `GET /api/learning-activity/textbook-progress?book={book}` | `completed_section_ids`、`last_section_id`、`history` | 真实进度、是否开始、最近学习时间 |
| 当前正式学习任务 | `GET /api/v1/dashboard/home` | `current_learning_task.learning_chapter.book` | 当前在学教材第一优先级 |
| 长期计划阶段 | `GET /api/v1/learning-path` | `nodes[]`、`current_node_id` | 获取长期计划全部阶段 |
| 每阶段计划教材 | `GET /api/v1/learning-path?parent_id={stageNodeId}` | `nodes[]` 中 `node_type = book` | 生成整个长期计划教材并集 |
| 教材分类标签 | `textbookPlanningLabel(book)`、Atlas 路线和现有 `stage_title` | 分类名称 | 卡片分类标签 |
| 教材封面 | `textbookCoverUrl(book)` | 静态资源 URL | 卡片封面 |
| 教材描述 | `textbookIntroduction(book)` | 描述字符串 | 悬浮/聚焦说明层 |

### 3.1 Atlas 一级字段含义

根据现有 Atlas 服务实现：

- `level=1` 的 `children_count` 是教材下的章节数量；
- `level=1` 的 `count` 是教材下的知识点总数；
- 因此章节数和知识点数无需前端解析 `alias` 文案，也无需为这两个指标重复遍历全部章节。

### 3.2 不能作为正式来源的字段

- 长期学习路径 book 节点的 `progress`：当前后端未保证它已经聚合真实教材学习记录；
- 长期学习路径 book 节点的 `status`：主要描述规划顺序，不能代替实际教材完成状态；
- `TextbookLibrary` 中的本地描述文案：只用于介绍，不得据此判断分类或状态；
- 前端固定百分比、固定章节数和固定知识点数：禁止使用。

## 4. 教材统一模型

第一版应在页面组件和展示组件之间增加统一的教材视图模型，避免 `TextbookLibrary` 自行拼接多个接口字段。

建议结构：

```js
{
  id: '中医学基础',
  name: '中医学基础',
  routeId: 'textbook_14_5',
  categoryLabel: '十四五规划教材',
  coverUrl: '/textbook-covers/中医学基础.jpg',
  description: '...',
  chapterCount: 16,
  knowledgePointCount: 120,
  totalSectionCount: 86,
  completedSectionCount: 24,
  progress: 0.279,
  hasStarted: true,
  isCompleted: false,
  isCurrent: true,
  isPlanned: true,
  lastSectionId: 'SEC_...',
  lastActivityAt: '2026-07-30T08:00:00Z',
  progressAvailable: true
}
```

所有跨接口教材名称比较必须先去掉 `《》` 并 `trim()`；优先复用现有 `normalizeBookName`，不得在列表组件中重复实现不同版本。

## 5. 学习进度计算

### 5.1 计算公式

```text
有效已完成小节 = completed_section_ids ∩ Atlas 当前教材有效小节 ID 集合
教材进度 = 有效已完成小节数 / Atlas 当前教材有效小节总数
```

- 百分比显示使用四舍五入后的整数；
- 计算值必须保留原始比例供状态判断；
- 已删除、重复或已不属于当前教材目录的历史 section ID 不计入分子；
- 当有效小节总数为 0，或目录/进度任一接口失败时，不显示伪造的 `0%`，应显示“进度待统计”。

### 5.2 已开始与已完成

```text
hasStarted = 有效已完成小节数 > 0
             或 progress.history 存在当前教材的有效学习记录
             或该教材被确定为当前在学教材

isCompleted = 有效小节总数 > 0 且有效已完成小节数 = 有效小节总数
```

仅打开教材目录但未产生任何小节学习记录，不自动算作已完成进度；若正式当前任务明确指向该教材，可以标记为“当前在学”。

## 6. 五个筛选项

### 6.1 全部教材

- 集合：Atlas `level=1` 返回的全部教材；
- 不受长期计划限制；
- 默认筛选项；
- 排序沿用 Atlas `order_index`；
- 保留现有渐进展开方式：有长期计划时首屏优先显示已加入计划的教材，并提供“展开全部教材”按钮；用户展开后再追加其余 Atlas 教材；
- 无长期计划时可直接展示 Atlas 全量教材；
- “全部教材”描述的是可进入的完整教材集合，不要求首次进入时同时请求每本教材的完整目录和进度。

### 6.2 学习中

- 定义：用户已经开始学习、但真实学习进度尚未达到 100% 的所有教材；
- 判断公式：`hasStarted = true 且 isCompleted = false`；
- 正常情况下可以显示多本，例如用户先后学习过 3 本教材且都未完成，则“学习中”显示 3 本；
- 当前正式任务指向的教材即使尚未完成第一个小节、进度暂为 0，也视为已经开始并进入“学习中”；
- 进度接口失败且当前任务也未指向该教材时，状态未知，不得默认归入“学习中”；
- 没有符合条件的教材时显示空状态“当前没有学习中的教材”。

“学习中”和“当前在学”是两个不同概念：

- “学习中”是筛选状态，可以有多本，表示所有已开始但未完成的教材；
- “当前在学”是唯一标记，复用页面顶部已经确定的 `currentBookName`，表示当前任务正在指向或用户最近正在继续的那一本教材；
- “当前在学”教材一定属于“学习中”，但“学习中”的其他教材不显示“当前在学”徽标。

### 6.3 未开始

- 集合：`hasStarted = false` 且 `isCompleted = false` 的教材；
- 当前在学教材即使进度暂为 0，也不得同时进入“未开始”；
- 进度接口失败时状态未知，不得默认归入“未开始”。

### 6.4 已完成

- 集合：`isCompleted = true` 的教材；
- 仅当真实教材进度达到 100% 时进入；
- 不使用学习路径节点 `status = completed` 代替真实教材完成状态。

### 6.5 已加入计划

- 定义：整个长期学习计划全部阶段的计划教材并集，不是当前学习阶段的教材；
- 加载根学习路径后，对每个 `stage` 节点请求一次 `GET /api/v1/learning-path?parent_id={stageNodeId}`；
- 汇总所有阶段的 `book` 节点，按标准化书名去重；
- 同一本教材出现在多个阶段时只展示一次；
- 计划教材不在当前 Atlas 路线时，不伪造教材卡片。应记录为数据质量问题，并在后续聚合接口中解决；
- 未生成长期计划时显示“尚未加入长期学习计划”。

## 7. 搜索、筛选与计数

- 搜索条件与当前筛选项取交集；
- 搜索范围包含标准化书名、分类标签和教材描述；
- 切换筛选项时保留搜索词；
- 每个筛选按钮的数量必须以 Atlas 完整教材集合为统计范围，不能随“展开全部教材”前后的可见卡片数量从计划教材数跳变为全量教材数；
- “全部教材”和“已加入计划”直接基于 Atlas 与长期计划显示完整数量；“学习中、未开始、已完成”在页面展示后由后台按最多 6 本并发逐步统计完整教材集合，数量更新不依赖用户是否点击“展开全部教材”；
- 区域右上角显示摘要：`共 X 本教材，其中 Y 本学习中`；其中 `Y` 是 `hasStarted = true 且 isCompleted = false` 的教材数量，可以大于 1；
- 筛选顺序固定为：全部教材、学习中、未开始、已完成、已加入计划；
- 未点击“展开全部教材”前，卡片区保持计划教材优先的首屏范围；点击展开后，筛选和搜索覆盖完整 Atlas 教材集合；筛选按钮上的“全部教材”数量在此过程中保持不变；
- 对尚未加载进度的教材，不提前计入“学习中、未开始、已完成”的确定数量，相关计数在按需数据加载完成后更新。

## 8. 教材卡片需求

### 8.1 固定展示字段

每张教材卡片必须展示：

1. 教材封面；
2. 分类标签；
3. 书名，视图层统一加 `《》`；
4. 章节总数；
5. 知识点总数；
6. 学习状态或已学习章节摘要；
7. 学习进度条；
8. 进度百分比或“进度待统计”；
9. “继续学习”按钮；
10. 当前在学标记。

### 8.2 分类标签

第一版复用现有前端来源，优先级如下：

1. `textbookPlanningLabel(book)` 的明确兼容映射；
2. 教材 Atlas 路线对应标签；
3. 计划节点已有的 `stage_title`；
4. 无可靠分类时显示“专业教材”。

分类标签只描述教材分类，不表达学习状态。“当前在学”必须使用独立状态标签。

### 8.3 当前在学标记

- `isCurrent = true` 时显示“当前在学”徽标；
- 同一时刻最多一张教材卡片显示该徽标；
- 徽标应靠近分类标签或书名，不能覆盖封面、章节数和进度；
- 切换当前教材或完成当前教材后，标记应随接口刷新同步移动或消失。

### 8.4 状态摘要

- 已开始但未完成：`已学习 {completedChapterEquivalent}/{chapterCount} 章` 不可直接由小节数伪装成章节数；如果没有可靠的已完成章节计算，应显示 `已完成 {completedSectionCount}/{totalSectionCount} 小节`；
- 未开始：显示“尚未开始”；
- 已完成：显示“已完成”；
- 进度不可用：显示“进度待统计”。

若要严格显示“已学习 X/Y 章”，必须按章判断其全部有效小节是否完成，再统计已完成章节数。

### 8.5 按钮和导航

- 按钮文案按本期要求统一为“继续学习”；
- 点击后进入对应教材目录：

```js
{
  page: 'practice',
  params: {
    view: 'textbook-chapters',
    route: book.routeId || 'textbook_14_5',
    lv1: book.name,
    source: 'textbook-library'
  }
}
```

- 教材目录页继续读取 `last_section_id`，用于恢复最近学习位置；
- 卡片容器不再使用包裹一切的 `<button>`。建议使用 `<article>` 加内部真实按钮，避免按钮嵌套并支持描述浮层。

## 9. 描述文字悬浮交互

### 9.1 桌面端

- 默认卡片不长期展示完整描述，释放空间给章节、知识点和进度；
- 鼠标进入卡片后显示描述浮层；
- 浮层应在卡片内部出现，不引起列表重排和页面跳动；
- 推荐使用从正文区域底部轻微上浮并淡入的遮罩层；
- 描述显示完整内容，不使用 `line-clamp`、省略号或固定行数截断；
- 浮层应根据描述长度提供足够空间；若极端长文案超过卡片安全高度，可在浮层内部滚动，但必须允许用户查看全部内容；
- 浮层不得遮挡或拦截“继续学习”按钮；
- 鼠标离开卡片后自然淡出。

### 9.2 键盘与移动端

- 键盘焦点进入卡片内的“继续学习”按钮时，也必须显示描述，不能只支持 `:hover`；
- 描述浮层使用 `:focus-within` 与 hover 同步；
- 移动端没有稳定 hover，第一版可保留一行截断描述或提供可点击的信息按钮；
- 描述不是业务状态，不应进入屏幕阅读器的重复播报链路；完整描述可通过按钮的 `aria-describedby` 关联。

## 10. 加载策略

### 10.1 第一版现有接口组合

第一版明确采用“前端缓存 + 先显示缓存 + 后台静默刷新”的 stale-while-revalidate 策略，不等待只读聚合接口上线。

1. 并行加载 Atlas 一级全量教材、`dashboard/home` 和学习路径根节点；
2. 学习路径根节点返回后，并行加载所有阶段教材，生成整个计划教材集合；
3. 首屏优先加载当前计划教材进度快照并立即展示页面；页面可用后在后台继续分批统计其余 Atlas 教材进度，用于完整筛选数量，后台统计不得重新遮盖页面或阻塞用户操作；
4. 用户点击“展开全部教材”后，立即显示 Atlas 静态字段；对应后台进度未完成的卡片继续显示“进度待统计”；
5. 对逐本请求设置并发上限，建议同时 4～6 本，避免一次性压满浏览器连接；
6. 以 `routeId + normalizedBookName` 为键缓存目录和进度快照；
7. 页面重新获得焦点、从教材目录返回、完成小节后，使对应教材进度缓存失效并刷新；
8. 单本教材加载失败只影响该卡片，不能阻塞其他教材展示。

### 10.2 第一版缓存与后台刷新

#### 缓存位置

- 主要使用前端模块级内存缓存，保证用户在教学资源页、教材目录页之间切换时可以立即恢复教材列表；
- 如需在浏览器刷新后继续命中缓存，可以增加 `sessionStorage` 缓存，但缓存键必须包含当前用户标识，并在退出登录、切换账号和收到 401 时清除；
- 不使用没有用户隔离的长期 `localStorage` 保存教材进度，避免不同账号看到旧用户状态。

#### 缓存键

```text
教材目录：atlas-catalog:{routeId}
长期计划：learning-path:{planId}:{planVersion}
教材快照：textbook-snapshot:{routeId}:{normalizedBookName}
当前任务：dashboard-current-task:{currentUserId}
```

#### 建议有效期

| 数据 | 新鲜时间 | 过期后的处理 |
| --- | --- | --- |
| Atlas 一级教材、章节和有效小节目录 | 30 分钟 | 先显示缓存，后台刷新 |
| 长期学习计划及全部阶段教材 | 5 分钟 | 先显示缓存，后台刷新 |
| 单本教材学习进度 | 60 秒 | 先显示缓存，后台刷新 |
| 当前正式学习任务 | 30 秒 | 先显示缓存，后台刷新 |

#### 页面行为

1. 有缓存时立即渲染，不显示覆盖整个教材区域的等待页；
2. 缓存仍在新鲜时间内时直接复用，不重复请求；
3. 缓存过期但仍可用时先显示旧值，并在后台发起刷新；
4. 后台返回新数据后，仅更新发生变化的教材卡片和筛选数量；
5. 后台刷新失败时保留缓存内容，并对受影响字段标记“更新失败”或继续显示最近同步时间；
6. 没有任何缓存的首次访问继续展示现有圆形加载指示器，不改成新的整页骨架屏；
7. 完成小节、刷新当前任务、重新生成长期计划后，立即使对应缓存失效，不等待 TTL；
8. 页面重新获得焦点或从教材目录返回时检查缓存是否过期，必要时静默刷新。

### 10.3 保留现有加载显示与按需展开

- 首次进入且没有可用缓存时，保留现有 `.workshop-library-page__loading` 圆形加载指示器；
- 不修改现有加载圈的尺寸、动画、颜色和占位方式；
- Atlas 一级目录加载成功后，结束加载圈并显示首屏教材；
- 有长期计划时首屏优先显示计划教材，并保留现有“展开全部教材”入口；
- 用户未展开时不展示剩余教材卡片，但页面可用后允许后台按并发上限统计剩余教材进度，以补齐全量筛选数量；
- 用户点击“展开全部教材”后，先立即追加可由 Atlas 一级节点展示的封面、书名、章节数和知识点数，再按 4～6 本的并发上限补齐新增教材进度；
- 新增卡片进度尚未返回时显示“正在统计”或“进度待统计”，不得闪现伪造的 `0%`；
- 有缓存时直接恢复上次已展示的数据，并在后台静默刷新，不额外显示覆盖页面的加载圈；
- 当前教材和计划归属可以独立更新徽标与筛选数量。

### 10.4 后续建议

当前方案会产生按教材和章节展开的多次请求。后续建议增加只读聚合接口，一次返回全量教材的章节数、知识点数、有效小节数、用户完成数、当前标记和计划归属。聚合接口只组合现有事实，不新增第二套持久化状态。

## 11. 空状态与错误状态

- 全部教材为空：显示“教材目录正在准备中”；
- 学习中为空：显示“当前没有学习中的教材”；
- 未开始为空：显示“暂无未开始教材”；
- 已完成为空：显示“还没有完成整本教材”；
- 已加入计划为空：显示“尚未加入长期学习计划”；
- 搜索无结果：显示“没有找到匹配的教材”；
- 单本进度失败：卡片仍展示封面、书名、章节数和知识点数，进度显示“进度待统计”；
- 计划接口失败：只禁用“已加入计划”结果，不影响全部教材和其他已加载状态。

## 12. 当前实现时需要修正的边界

1. 保留 `visibleWorkshopTextbooks` 的计划教材优先展示和“展开全部教材”交互；Atlas 全量教材仍作为完整数据基表，但首屏不要求逐本加载全部教材进度；
2. `plannedBooks` 当前已经汇总所有阶段，不能改用 `currentStageBooks` 实现“已加入计划”；
3. 顶部学习计划的“计划教材”仍统计当前阶段教材，与教材区域的“已加入计划”不是同一范围，字段命名和 selector 必须区分；
4. 当前 `TextbookLibrary` 整张卡片是按钮，加入悬浮描述和内部操作按钮时需要调整语义结构；
5. 当前分类标签存在本地兼容映射，不能把 `stage_title` 当作唯一分类真相；
6. 教材进度必须复用教材目录页的正式计算函数，不得在卡片组件中再次独立计算；
7. 不能把 `completed_section_ids.length` 直接除以未校验的历史总数，也不能把完成小节数显示成完成章节数。

## 13. 验收标准

1. 点击“展开全部教材”后，展示数量与 Atlas 一级教材数量一致；未展开时保持计划教材优先的首屏范围；
2. “学习中”包含全部已开始但未完成的教材，可以有多本；顶部绿色学习任务卡对应的教材必须位于其中；
3. 同一时刻最多一张卡片带“当前在学”徽标，且与顶部绿色学习任务卡一致；
4. 当前教材即使尚未完成第一个小节，也不会出现在“未开始”；
5. 教材完成最后一个有效小节后，进度变为 100%，进入“已完成”，并退出“学习中”；
6. “已加入计划”包含长期计划每一个阶段的教材并集，而不只是当前阶段教材；
7. 同一本教材出现在多个阶段时，“已加入计划”只展示一次；
8. 卡片章节总数使用 Atlas 一级节点 `children_count`，知识点总数使用 `count`；
9. 进度与教材目录页一致，历史无效 section ID 不影响百分比；
10. 没有可靠进度时显示“进度待统计”，不显示伪造的 0%；
11. 卡片默认不长期占用空间展示完整描述；鼠标悬浮和键盘聚焦时均可查看完整描述，不截断内容；
12. 描述浮层出现和消失时列表不跳动，且不遮挡“继续学习”按钮；
13. 点击“继续学习”进入对应教材目录，并携带正确的 `route` 与 `lv1`；
14. 搜索与五种筛选可以组合使用，切换筛选不清空搜索词；
15. 单个接口或单本教材加载失败时，其他教材仍可正常展示和进入；
16. 有缓存时页面先显示缓存并后台刷新；只有首次且无缓存时显示现有圆形加载指示器；
17. 未展开全部教材时不逐本请求剩余教材进度；点击展开后才按批次加载新增教材；
18. 桌面端维持参考图的双列卡片布局，窄屏自动切换单列，不产生横向滚动。

## 14. 建议测试范围

- 单元测试：教材名归一化、进度交集、章节完成数、五类筛选、全阶段计划去重、当前教材唯一性；
- 组件测试：五个筛选按钮、搜索与筛选组合、卡片字段、当前徽标、悬浮/聚焦描述、继续学习导航；
- 异常测试：Atlas 一级失败、单本目录失败、单本进度失败、计划接口失败、当前任务为空；
- 集成测试：完成教材小节后返回列表，进度和筛选即时更新；
- 回归测试：顶部学习计划仍使用当前阶段教材统计，教材列表的“已加入计划”使用全部阶段教材统计。

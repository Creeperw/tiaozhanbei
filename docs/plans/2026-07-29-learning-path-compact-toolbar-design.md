# 学习路径紧凑工具栏与规划详情设计

## 目标

将学习路径主框顶部整理为一条稳定、紧凑且顺序明确的工具栏，并把规划详情改成适合连续阅读的单列 Markdown 文档。

## 已确认布局

学习路径工具栏在桌面端固定保持一行，控件顺序为：

`考试类别名称 → 学习阶段 → 学习路径 → 经典路径 → 个性化路径 → 规划详情`

- 考试类别名称缩小字号，但保持完整显示。
- 五个按钮采用一致的紧凑高度、圆角、字号和横向留白。
- “学习阶段 / 学习路径”保留更醒目的当前视图状态。
- “经典路径 / 个性化路径”紧随视图切换之后。
- “规划详情”作为最右侧按钮；进入详情后文案切换为“返回路径”。
- “学情调研”离开工具栏，移动到首页英雄区“签到”按钮下方。
- 桌面端不换行；窄屏时工具栏整体横向滚动，避免按钮和完整考试名称被截断。

## 规划详情

- 长期规划与短期规划不再并排分栏，而是在同一张单列文档中依次展示。
- 页面顺序为“长期规划”在前、“短期规划”在后，两部分之间用清晰但轻量的章节标题分隔。
- Markdown 继续支持标题、段落、列表、强调和 GFM 表格。
- 表格取消固定最小宽度，使用当前内容区宽度；列宽由浏览器均衡分配，单元格允许自动换行和长文本断行。
- 详情容器仅纵向滚动，普通规划内容不产生横向滚动条。

## 响应式与可访问性

- 桌面端标题和所有控件处于同一行，工具栏自身使用 `white-space: nowrap`。
- 小屏不改变控件顺序，提供工具栏横向滚动作为兜底。
- 保留现有 `role="group"`、`aria-label` 和 `aria-pressed` 状态。
- 规划详情仍使用具名 `region`，Markdown 标题、列表和表格保留原生语义。

## 验证

- 组件测试断言工具栏三个直接子区域的顺序，以及“规划详情”“学情调研”的新位置。
- 组件测试断言规划详情只有一列，长期规划位于短期规划之前。
- Markdown 测试断言标题、列表和表格仍被渲染为语义元素。
- CSS 源码测试断言工具栏不换行、按钮统一尺寸，以及规划表格无固定最小宽度并允许换行。
- 运行相关 Vitest、生产构建和 `git diff --check`。

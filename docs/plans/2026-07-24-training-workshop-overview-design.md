# 训练工坊总览设计

## 目标

将训练工坊改为总览入口。学习者先在一页内看到主要训练路径、高频学习工具与真实学习摘要，再进入既有训练工作区完成作答、模拟或组卷。

## 信息架构

- `训练工坊` 默认展示总览。
- 点击训练卡片时，以既有 `taskType` 参数进入 `PracticePage` 的对应训练面板。
- 训练工作区提供“返回训练工坊”操作，回到总览。
- 现有训练结果面板与移动端“任务 / 结果”切换保持不变。

## 总览布局

- 顶部为浅绿色训练横幅，包含“训练工坊，实战精进”标题、简短说明和清单、试卷、笔的学习插画。
- 桌面端主体采用“训练路径主区 + 高频工具侧栏”：主区为两列训练卡片，侧栏为紧凑工具卡片。
- 训练卡片包括：综合训练、专项题型、智能组卷、错题变式、模拟病患、专题训练。
- 专题训练以正式 `kp_id` 知识点为最小训练单位，不再以宽泛的自由文本“专题”直接抽题。
- 专题训练页分为两个板块：
	- **今日要训练的知识点**：读取当前每日任务的 `knowledge_cards` 及知识练习任务项，保持计划中的知识点顺序；学习者点击后直接进入对应 `kp_id` 的训练。
	- **全部教材知识点**：沿用知识图谱正式教材层级，按“教材 → 章节 → 小节 → 知识点”逐层选择；当前知识点没有可训练题目时显示“待补题”，不伪造训练内容。
- 每日任务中 `knowledge_practice` 类型的“开始”操作统一进入专题训练，并携带 `taskItemId`、正式 `kpId` 与 `kpName`，继续使用冻结题目、进度统计和任务完成写回机制。
- 从每日任务进入后锁定该知识点，不能切换到其他知识点并继续写回同一任务项；任务项缺少正式知识点绑定时失败关闭。
- 显式选择知识点时，出题服务只接受关联中包含该 `kp_id` 的候选；当前题型无匹配题时返回空状态，不跨知识点兜底。
- 高频工具包括：错题库、知识收藏、学习笔记。三者均提供正式工作区；知识收藏支持收藏簿管理和已批改题目收藏，学习笔记支持独立笔记及题目上下文笔记的新增、修改、检索与删除。
- 知识收藏和学习笔记使用服务端持久化，数据所有权只由登录会话确定，不通过请求体传递用户 ID，也不再使用浏览器 `localStorage` 作为正式数据源。
- 智能组卷和资格套题仅在服务端批改完成后显示“加入收藏”“记笔记”，保存题干、选项、用户答案、标准答案和解析，避免作答前泄露答案。
- 底部使用摘要栏展示可用的学习统计。未获得真实数据时展示“暂无记录”。

## 交互与可访问性

- 全部可用卡片使用语义化按钮，支持键盘激活、可见焦点和 44px 以上触控区域。
- 卡片悬停仅使用颜色、边框和阴影过渡，不改变布局尺寸。
- 移动端使用单列卡片布局；训练工作区沿用已有的移动端任务与结果切换。
- 视觉沿用项目的侧栏、字体和绿色品牌色，参考图仅作为信息层级与轻量插画氛围的依据。

## 验收

- 训练工坊默认显示总览，训练卡片可打开对应的现有训练工作区。
- 工作区可以返回总览；现有题目训练、AI 病患模拟、错题变式和试卷生成不回归。
- 专题训练默认先展示每日任务知识点和全部教材知识点两个板块；选定知识点后只从该 `kp_id` 关联题目中训练。
- 每日任务知识练习从首页点击后进入专题训练，页面锁定任务项对应的正式知识点，作答仍绑定原任务项并正确累计完成进度。
- 全部教材知识点使用正式知识图谱层级，能够扩展到每本书的完整知识点集合；无题知识点不可进入空训练。
- 单元测试覆盖入口、跳转、返回和已有工作区行为。
- 通过前端单元测试、lint、生产构建，并在桌面与移动视口截图确认无溢出或遮挡。

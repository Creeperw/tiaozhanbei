# 首页能力模块创新点设计

日期：2026-07-29

## 已确认的信息架构

首页下方保持四张能力卡片，采用用户易理解的短标题承载创新机制：

1. **多智能体协同**：学情诊断、学习规划、专家等六大智能体协同处理学习任务，按需分工，每项建议都关联证据、约束与审核结果，贯穿学习全流程完成诊断、答疑与学习支持。
2. **个性化学习路径**：结合考试目标、阶段计划与近期答题表现，在前置知识、复习到期和可用时间等约束下，生成可解释、可调整的学习路径。
3. **专项训练**：围绕薄弱点提供章节练习、错题变式、病例训练与试卷生成，把诊断结论转化为可完成的训练任务。
4. **人机协同**：学生可确认目标与时间、调整难度或更换资源，并查看推荐依据；任务反馈与完成效果共同进入下一轮路径和资源匹配。

## 映射原则

- 创新点一进入“多智能体协同”的说明，突出证据、约束与审核链路。
- 创新点二进入“个性化学习路径”的说明，突出多时间尺度和硬约束。
- 创新点三由“人机协同”承接，突出学生对路径调整的参与权与反馈闭环。
- 保持原有卡片布局、图标节奏和“点击进入能力详情”的交互模式。

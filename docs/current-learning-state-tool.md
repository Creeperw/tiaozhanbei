# 当前学习状态只读工具

## 接口

- 名称：`get_current_learning_state`。
- 输入：`view`（overview/textbook/section/today）、`book_id`、`section_id`、`cursor`、`limit`（1–20，默认8）。
- 不接受模型传入账号或考试；身份来自已绑定的考试工作区。
- `book_id` 当前使用规范教材名称；只能选择当前计划教材或无计划时已有学习记录中的教材。
- `section_id` 必须属于所选教材的规范目录；未解析目录不用于推断推进顺序。
- 每次读取提供 `snapshot_id`、`source_version`、`observed_at`。翻页须比较版本，不可拼接不同版本结果。

## 事实语义

- 完成记录复用教材页面同一过滤函数，按账号、考试、教材隔离。
- 完成、掌握度、今日任务执行分别输出。演示来源保持 `authorized_demo`；无来源历史记录为 `unspecified`。
- 分开输出最近记录完成、最近演示补记、顺序最远完成、前序缺口、后续候选。无可靠访问记录时 `last_visited_section=null`。
- 前序缺口不等于必须回到绪论；无完成记录不等于从未学过。
- 掌握度只读取有作答证据的当前考试投影，并使用审核通过的等价知识点映射；歧义映射不合并数值。
- 今日项目执行状态按当前任务ID、版本和用户读取。没有执行记录时状态为unknown；实际用时没有可靠来源时为null。
- 到期复习池与调度明确选中的复习任务分开；旧任务缺少调度合同则安排情况为unknown。
- 资源只读取已有目录，不联网、不注册资源、不生成题目；推荐视频不代表精确小节覆盖。题量为目录去重计数，不承诺满足全部可执行题目约束。
- 复习队列上限200，教材列表和完成证据有界；截断会显式标记。

## 接入与副作用

- Planner先完成语义路由，仅学习规划分支且具体考试已绑定时加载快照。
- Diagnosis只读问答的当前进度、下一步、计划进度、复习状态枚举接入新工具；不传入用户身份参数，不调用计划发布服务。历史学习活动、专项掌握度查询仍使用对应原工具。
- Knowledge、Diagnosis、Audit共享同一运行快照；正文编译器不注入该附加事实。
- 同步目录/数据库读取通过工作线程执行；发布锁内复核使用同线程只读入口，避免锁等待死锁。
- 发布前重新检查计划、考试、完成记录、掌握度、执行记录、复习及目录摘要。发现变更或读取不可用时返回重新生成提示，不发布基于旧状态的计划。
- 这是发布前检查，不是跨数据库分布式事务；检查后到最终写入之间仍存在并发窗口。既有计划头CAS继续负责计划版本冲突。
- 不创建用户、不flush/commit、不调度复习、不重建学习状态。目录缓存仅在进程内加载。
- 旧工具名保留兼容；已绑定考试转到新工具，无考试stub兼容调用仍走旧分支。
- 此次不修改任务预算、空核心任务兜底、复习页面固定时长等已知业务问题。

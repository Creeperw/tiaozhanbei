 

# 推荐的五个核心创新点

| 创新点                                                | 核心表述                                                                                                                      | 当前基础                                                                                                                                                                                                                                                                                                   | 还需补强                                                                                                     |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **1. 任务自适应的异构智能体协同与双重裁决**     | 不采用固定流水线，而是根据任务意图动态选择 Agent、构建依赖 DAG；采用“模型审核 + 确定性规则”双重裁决，支持复杂返修和人工升级 | Planner 已针对讲解、规划、复习卡、组卷生成不同执行计划，`planner.py`（line 492）；LangGraph 根据计划动态编译 DAG，`langgraph_orchestrator.py`（line 224）；审核可返修或转人工，`langgraph_orchestrator.py`（line 410）                                                                               | 增加“高风险触发的证据检索 Agent”，形成专家提案—证据反驳—裁判裁决，而不是全流程无差别辩论                 |
| **2. 多层证据图谱驱动的声明级可信生成**         | 将知识检索结果组织成带来源等级、置信度、关联层级的证据包；生成内容中的专业声明必须绑定证据 ID，弱证据只能支持低风险表述       | 题库采用 Bridge、BM25、向量三路融合，`question_retrieval.py`（line 56）；`strict/llm/similarity` 分层排序，`question_retrieval.py`（line 168）；弱证据被标记为风险，`knowledge_retrieval.py`（line 111）；资源声明绑定证据，`expert.py`（line 379）；审核会拦截缺证声明，`audit.py`（line 27） | 建立声明级“证据覆盖率、引用准确率、幻觉率”测评，而不只让另一个 LLM 给分                                    |
| **3. 置信感知的学习者数字画像与“保守个性化”** | 个性化决策不仅看用户标签，还考虑画像证据的样本量、新鲜度和可靠性；数据不足时主动降低诊断置信度，避免“伪个性化”              | 监控快照计算活动、作答、掌握记录样本量及数据新鲜度，`learning_monitoring.py`（line 12）；样本不足时诊断 Agent 明确降置信，`diagnosis.py`（line 92）；资源同时适配目标难度和可用时长，`expert.py`（line 379）                                                                                         | 定义“画像—资源匹配分”：知识缺口、遗忘紧迫度、难度适配、目标相关性、证据可靠性五维联合评分，并展示匹配曲线 |
| **4. 多时间尺度、抗震荡的动态学习闭环**         | 把长期路线、1–2 周短期计划和当日任务分层决策；单次答错只调整当日资源，只有持续变化才更新上层计划，避免计划频繁震荡           | 计划划分区分长期、短期和当日三个层级，`learning_plan.py`（line 12）；计划门禁只更新发生明确变化的层级，并禁止单次表现改写长期计划，`plan_change_gate.py`（line 24）                                                                                                                                    | 将“答题—掌握度—资源难度—复习时间—计划层级”状态转移完整可视化，形成答辩中的闭环演示                     |
| **5. 面向垂直领域的可审计、最小权限智能体治理** | Agent 不只是角色分工，还受到数据权限、输出契约、审核前置条件和写回幂等约束；每次决策可回放、可追责、可脱敏导出                | 最小权限能力清单及画像写入确认，`data_permission.py`（line 19）；只有审核通过才能发布，`writeback.py`（line 75）；快照自动清除密钥、手机号和身份证号，`snapshot.py`（line 11）；前端展示真实 Agent 轨迹和人工等待状态，`AgentTimeline.jsx`（line 146）                                             | 把权限拒绝率、未审核发布率、轨迹完整率和敏感信息泄漏率纳入验收指标                                           |
